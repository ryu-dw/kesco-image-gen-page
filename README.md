# kesco-image-gen-page

한글 포스터 생성 테스트 페이지(정적 HTML). 그림 생성은 별도로 떠 있는 `kesco-image-gen-api` 서버가 하고, 이 페이지는 그 서버를 호출한다.

- `index.html` 틀·자동 배치 테스트 페이지
- `chat.html` 대화형 페이지

## 사용

1. API 서버를 띄운다 (`kesco-image-gen-api`, 기본 `http://127.0.0.1:8090`).
2. 이 페이지를 열고 헤더의 **API** 칸에 서버 주소를 넣고 **적용**을 누른다. 주소는 브라우저에 기억된다.
   또는 주소 뒤에 `?api=http://127.0.0.1:8090` 을 붙여 연다.
3. 브라우저 보안 정책상 https 페이지에서 부를 수 있는 API 주소는 `http://127.0.0.1`·`http://localhost` 또는 `https://…` 뿐이다. 다른 http 주소는 차단된다.

이 저장소에는 서버 주소·인증 정보가 들어 있지 않다.
